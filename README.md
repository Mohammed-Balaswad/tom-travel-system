# TOM – Travel Management System

TOM is an academic project aimed at building a digital travel and tourism platform.

## Project Structure
- backend/ → Laravel REST API
- mobile/  → Flutter mobile application
- figma/   → UI/UX design assets

## Project Status
🚧 In progress – the system is under active development.

## Purpose
This project was developed as part of the **Advanced Web** course to apply modern concepts in backend development, mobile applications, and system architecture.
